### 远程策略建议

若**必须远程 + 尽量高薪**：
1. **主线**：天弘/华创/东方财富拿 offer 后谈 hybrid（部分金融 AI 岗可谈每周 1–2 天远程，但纯远程罕见）
2. **副线**：TalentsAI 专家入驻（已备材料，时薪叠加，不影响在职）
3. **激进线**：TOP 交易所类 crypto Agent 岗（薪资最高，行业与合规风险也最高）

## 三、分项详解：最值得投的 5 个岗

### 1. 天弘基金 · 投研大模型算法工程师｜北京｜30–60k·20薪

- **链接**：https://www.liepin.com/job/1984756949.shtml
- **为什么排第一**：JD 第 3–5 条几乎逐条对应你的经历——Agent Harness/Skills、Claude Code/Cursor 开发方式、公告/财报/研报数据形态、投研场景评测迭代。
- **年薪区间**：60–120 万（按 20 薪计）
- **你的优势**：正知 Skill 管道 + 独立研究回测 + 江铜 FOF 尽调
- **缺口**：「算法功底扎实、了解强化学习」；顶会论文是优先项非硬门槛
- **投递策略**：把 Skill 全文 + 证据表放简历最前；算法部分诚实写「应用层算法工程师，非模型训练」

### 2. 百亿私募 · AI Agent 工程师｜上海｜50–80k·16薪

- **链接**：https://www.liepin.com/a/77672395.shtml
- **年薪区间**：80–128 万
- **为什么值得冲**：要求「从 0 到 1 构建生产级智能应用，非 demo」——你的巨潮采集管道 + cron 部署 + 断言校验正好是这个叙事
- **缺口**：要求 Go/Python 复杂后端；你只有 Python
- **风险**：私募节奏快，反馈结构可能重蹈量盈覆辙

### 3. 华创证券 · 金融 AI Agent 开发｜上海｜本科即可

- **链接**：https://www.zhaopin.com/jobdetail/CC330089720J40845512609.htm
- **为什么匹配度最高**：JD 原文写 **MCP/Skills 体系建设、Benchmark/回归测试**；加分项写 Claude Code/Cursor + 个人 Agent Repo——这是市场上极少数「把你的做法写进 JD」的岗
- **薪资**：智联未标，同类券商 AI 应用岗通常 25–40k，低于私募但胜在稳定 + 命中率高
- **缺口**：Java/TypeScript 至少熟练一项；投前把脱敏 Skill 推公开仓库

### 4. 东方财富证券 · AI Agent 架构师｜上海｜40–70k·16薪

- **链接**：https://www.liepin.com/job/1983831601.shtml
- **年薪区间**：64–112 万
- **亮点**：证券业务 + 从 0 到 1 Agent 项目 + LangChain
- **缺口**：要求 5 年开发 + 2 年 AI 经验——你总从业 7 年但「开发」口径可能被质疑；沟通协调是明确硬要求
- **判断**：**高薪资但命中率中等**，值得投，简历里把「独立研究期间系统建设」折算为开发年限

### 5. TOP 交易所 · Agent 创新应用算法工程师｜远程｜年包≤120万

- **链接**：https://github.com/rebase-network/who-is-hiring/issues/1203
- **为什么薪资最高**：远程 + 年包 120 万以内 + JD 写满 Skills/MCP/Agentic Coding
- **你的命中点**：Skill 封装编排、金融交易经验、Agent 评测意识
- **硬伤**：要 PyTorch/深度学习框架；招聘帖已因公司信息不全被关闭，需通过 VX/TG 私信确认是否仍招
- **行业风险**：crypto 监管、发薪 USDT、工作稳定性——投前想清楚
