# 岗位机会地图 · 殷维（2026-08-24 扫描）

> 按 get-job.skill Stage 1 做的市场扫描，不是单岗调研。目标市场：中国大陆社招。
> 输入变量：新增正知资产 2026.06 至今约 3 个月的 AI 投研工程经验。

## 来源覆盖说明

- **A 级（招聘方原文）**：猎聘/智联/全职招聘网上的 JD 全文（好买财富、天弘基金、华创证券、国信证券、排排网、利安人寿、长江证券、长信基金、中信保诚等）；徽银理财社招公告。
- **B 级**：财联社关于 2026 年券商 AI 人才争夺的报道（华泰招主观权益 AI 投研平台产品经理、国联民生招数字化产品经理）；广发证券 Skill Hub / MCP 工作台的公开披露。
- **C 级**：行业常识（券商投研数字化条线分工）。
- **D 级**：无面经可用，未使用。
- **缺口**：多数 JD 未写团队规模与汇报关系；薪资区间来自平台展示，可能与实发不符；部分岗位更新日期较早，投前需确认是否仍在招。

## 一、结论先说：定位变了

这三个月最重要的变化不是「多了一段经历」，而是**候选人从「有短板的量化研究员」变成了「懂投研业务、能把 AI 落地的人」**——后者在 2026 年是稀缺交叉，前者是红海。

四家不同类型的机构在 JD 里几乎点名了这个组合：

| 机构 | JD 原话（节选） |
|------|----------------|
| 天弘基金 | 熟练使用 AI Coding 工具与智能体编程方式（如 Claude Code、Cursor）…有从 0 到 1 独立构建系统的能力；理解投研，熟悉行情、财报、研报、公告等数据形态 |
| 华创证券 | MCP/Skills 体系建设：能力封装、权限与策略、可观测与回放；**加分：有个人 Agent 作品或开源项目（可提供 Demo/Repo）** |
| 好买财富 | 作为投研中央金融工程师，搭建公私募基金投研业务的 AI Agent；**有二级市场基金研究经验者加分** |
| 排排网 | 或具备 **AI 大模型开发应用**、基金定量评价等相关经验者优先 |

候选人手上对应的实物：两个 Agent Skill（盘中热点、巨潮采集）、连续多月落盘的分钟热度表、PDF 解析+多源兜底的公告管道、Linux 定时任务与启停脚本、可脱离行情平台的回测账户模拟。

## 二、但有一个立刻要修的问题：术语没对齐

候选人做的事和市场要的事高度重合，**用的词却不一样**，导致 HR 检索和简历初筛看不见。

| 现在怎么写 | 市场检索的词 |
|------------|--------------|
| Cursor Skill / SKILL.md | Agent 编排、Skills 体系、工具调用、MCP |
| Coze 工作流 | Workflow 编排、Dify / LangGraph 同类 |
| 巨潮 PDF 解析 + 东财兜底 | 非结构化数据解析、多源召回与降级策略（RAG 前置管道） |
| 对落盘表做断言校验 | 评测集、回归测试、benchmark |
| cron + 启停脚本 + 日志 | 服务可观测性、任务调度、稳定性保障 |

这不是包装，是同义翻译。做过的事没变。**这一步不做，下面所有第一层岗位的简历都会卡在初筛。**

真正缺的只有框架名：LangChain / LangGraph / Dify / RAG 评估（ragas）。以候选人的自学速度和 AI 辅助能力，补一个能跑的 demo 成本很低，而且补完就能诚实地写进简历。

## 三、第一层：交叉卡位，优先投

这层的共同点是「金融业务理解」和「AI 落地」都要，正好卡在候选人的能力交点上。

### 1. 好买财富 · AI 应用工程师（量化投研部）｜上海浦东｜18-28k｜1-3年｜硕士

- 链接：https://www.liepin.com/job/1983674751.shtml
- 为什么排第一：JD 把岗位定义成「投研中央金融工程师，搭建公私募基金投研业务的 AI Agent」。这同时命中候选人两条最强线——基金研究（江铜尽调）和 AI 工程（正知）。而且明确写「有二级市场基金研究经验者加分」。
- 匹配：硕士、1-3年、金融+AI 复合、量化投研部归属。
- 缺口：langchain / langgraph / deer-flow / RAG / ragas 这套框架没写过。**投前必须补一个 demo**，否则第 4 条硬要求直接被筛。
- 风险：三方财富机构，业务节奏偏快。

### 2. 天弘基金 · 投研大模型算法工程师｜北京｜硕士

- 链接：https://www.liepin.com/job/1984756949.shtml
- 为什么值得试：JD 第 3、4、5 条几乎是照着候选人写的——Agent Harness 生态（Skills、工具调用）、用 Claude Code/Cursor 以「人定义问题、AI 生成实现」的方式交付、理解投研且熟悉公告财报研报数据形态。
- 缺口：要求「算法功底扎实、了解强化学习」，且「NLP/ML 顶会论文或竞赛获奖者优先」。后者是优先项不是硬门槛，但前者是真门槛。
- 判断：这是一个**高回报但低命中率**的投递。值得投，别指望它。简历要把 Skill 和公告管道放最前，算法部分诚实留白。

### 3. 华创证券 · 金融 AI Agent 开发（基金投顾方向）

- 链接：https://www.zhaopin.com/jobdetail/CC330089720J40845512609.htm
- 亮点：学历只要本科；JD 直接写 **MCP/Skills 体系建设**，加分项写明「深度使用过 Claude Code/Codex/Cursor（有工程化工作流更佳）」「有个人 Agent 作品或开源项目，可提供 Demo/Repo/技术文章」。候选人正好两样都有。
- 缺口：要 Java / Python / TypeScript 至少熟练两项，岗位偏后端服务架构。候选人只有 Python，这是硬伤。
- 判断：把脱敏 Skill 放到公开仓库后再投，用作品弥补语言栈。命中率中等。

## 七、地点这件事要正面面对

第一层三个岗位分别在上海、北京、深圳/北京；第二层几乎全在上海。武汉本地只有长江证券一个，还不对口。

**想走「金融 × AI」这条线，大概率要离开武汉。** 这个取舍现在就要想清楚，不然投到中后段会反复摇摆。如果必须留武汉，那现实选项是继续在武汉的私募/券商分支做量化，天花板和岗位密度都明显低一档。

## 八、行动顺序

1. **先改简历术语**（半天）：按第二节的对照表把现有 bullet 翻译一遍。不改事实，只改词。
2. **补一个 LangChain 或 Dify 的小 demo**（几天）：把现有的巨潮采集或涨停监控其中一条，用主流框架重写一版，跑通即可。补完第一层三个岗位的硬门槛就都能诚实地写。
3. **把脱敏 Skill 推到公开仓库**：华创明确把「个人 Agent 作品/Repo」写成加分项，这是零成本的差异化。
4. **投递批次**：第一批投好买财富 + 华创 + 国联民生（材料现成）；第二批投天弘投研大模型 + 第二层的利安人寿、华宝、中信期货。
5. **排排网谨慎**：AI 加分项很对口，但每月 12 家尽调 + 强沟通要求，投之前先想清楚能不能接受。

## 九、需要候选人确认的

- 能否接受上海/北京长期工作？这决定第一层要不要全力投。
- 现任正知是否满 3 个月、是否方便面试？在职跳槽的节奏要安排。
- 补 demo 这件事愿不愿意花时间？不补的话第一层基本只能碰运气。
