# 出题样例 · TalentsAI Agentic Coding × 金融

对照平台看的六件事：考察点、输入是否合理、输出是否可验证、测试是否严谨、Agent 会不会投机、是否贴近真实场景。四道题都来自本人做过的工作，不是 LeetCode 换皮。

## 样题 1｜A 股涨停判定（easy，20–30 分钟）

- 场景：盘中涨停监控的第一步。
- 规则必须写进 instruction：主板 10%；创业板/科创板 20%；北交所 30%；ST 5%。比较前先四舍五入到百分号后两位。
- 输入 `quotes.csv`，输出 `limit_up.csv`（code, 0/1，按 code 升序）。
- 防投机：隐藏测例；卡在阈值上的票（创业板 19.99%）必须判 0，防止「涨幅>9.5 就算涨停」。

## 样题 2｜业绩预告与快报拆开入库（medium，45–70 分钟）

- 场景：全市场预告/快报采集。两类数字不能合成一条；必须用公告日做 point-in-time。
- 类型只允许 forecast / flash / regular；缺省变动幅度写 NA 禁止填 0。
- 防投机：脏样本（预告数字写在快报标题下）；禁止按文件名猜类型。

## 样题 3｜强势股位置过滤 + 对照回测（medium，60–90 分钟）

- 场景：现任验证过的规则 `close / 前20日最低 < 1.3`，对照后最大单笔亏损从约 -27% 收到约 -17%。
- 必须输出两组对照指标，而不是一条净值。20 日窗口不含当日，停牌不计入。
- 防投机：成交明细对不上则失败；禁止读取「标准答案收益」。

## 样题 4｜分钟板块热度合成日线回测（hard，2–3 小时）

- 场景：掘金短线多头。分钟因子 14:30 截断；板块成分用当日可交易名单。
- 涨停买不进、跌停卖不出；成本费率写死。
- 防投机：把 14:45 改成极端值，结果若变则判定未来函数；信号日改涨停则成交必须为 0。
- 不出 sklearn/xgboost 选股题，那不是我的工作栈。
