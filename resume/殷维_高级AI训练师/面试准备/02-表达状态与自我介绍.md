# 表达状态与自我介绍 · 高级AI训练师

> 固定准备文件。目标：不卑不亢，把量化研究背景讲成对训练师有用，而不是先道歉。

## 面试姿态

| 要做到 | 不要这样 |
|--------|----------|
| 开场先说「履历是量化研究，我来投 AI 训练：语气、步骤、校验」 | 一上来「我不是学传播的，可能不太合适」 |
| 主动把智能体 / 日报和公告校验讲到同事怎么用 | 只说「我用过 Coze / LangGraph」 |
| 缺的立刻画边界：MJ、剧本、虚拟人 | 用「人格工程」「造梦师」去凑 |
| 英语六级 558 可以提，不装口语母语 | 主动承诺能独立做国际角色设定 |

## 通用自我介绍（45 秒口语版）

> 您好，我是殷维，量化研究背景，华科金融硕士。最近在私募做 AI 投研：把投研智能体接到微信和飞书，日报做成定时、格式一致，同事每天用得到再改语气；公告数字拆成采集、校验、换源，不让模型一次生成当定稿。我也给看盘同事做分时段短推送，写能扫一眼的要点。我投这个岗，是因为你们要的是人设稳定、提示词能复用、输出能检查。我没有写过社交角色剧本，也没用过 Midjourney，但我在投研侧完整做过语气、步骤和质检。您要是对智能体怎么改口吻、或校验怎么拆更感兴趣，我可以展开。

## 关键字卡

- 量化研究履历，投 AI 训练师
- 智能体接到微信 / 飞书，先能用再改语气
- 日报：定时、格式一致、多人共用
- 公告：采集、校验、换源
- 分时段短内容，不是长研报
- 没用过 MJ/SD，没写过虚拟人剧本

## 项目逐字稿 · 智能体 + 日报（90 秒）

| 模块 | 该怎么讲 |
|------|----------|
| 背景 | 同事要每天用得到的投研助手，不要再开一套没人看的后台。 |
| 我做了什么 | 选型接到微信 / 飞书；日报定时、栏目固定；待办定点提醒。 |
| 分步怎么做 | 先打通入口；再定栏目和口吻；再看同事还要不要、改哪一句。 |
| 结果 | 工作日能跑到常用聊天工具。使用者是内部同事，不是 C 端社交用户。 |
| 困难 | 模型容易写成研报腔，或漏栏目。所以格式和验收要比「更会写」优先。 |
| 下次优化 | 先把「还要哪几个字段、哪句话不像平时」收稳，不先做人设宇宙。 |

## 项目逐字稿 · 公告采集（60 秒）

| 模块 | 该怎么讲 |
|------|----------|
| 背景 | 「帮我盯净利润」这种任务，模型容易漏或编。 |
| 我做了什么 | 拆成采集、校验、失败换源。 |
| 分步怎么做 | 先定要哪个数字，再采公开公告，对不上就换源，不对就不往下走。 |
| 结果 | 有可跑的 LangGraph demo，GitHub 能打开。 |
| 困难 | 源不稳定、字段不齐。所以失败路径比「一次抽对」更重要。 |
| 下次优化 | 继续加校验；社交人设里我还没做过同等标注。 |
