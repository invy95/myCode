## 核心能力关键词（简历要对齐的靶心）

## 加分 / 减分（对殷维）

**加分（有真实锚点）**

- 自己就是策略研究者：短线、财报、赛道轮动、因子回测，懂「专业用户要可核对的东西」。
- 把「找强势股」收成带 130% 过滤的规则，并用对照回测看最大单笔亏损变化——这就是「意图 → 结构化策略 + 风控」。
- 公告采集做成采集 → 校验 → 失败换源，不把模型输出当成交/配置指令。
- 正知从工具选型做到微信/飞书推送能用，符合「独立拆方案、低成本验证」。
- 2026 年在用 Claude / Cursor / MCP / Coze / LangGraph；Xpert、TalentsAI 已过审（远程交付证据，不是全职经历）。

**减分 / 必须诚实**

- 没有产品经理职称，没有 C 端 PRD、用户访谈、埋点、A/B。不能写成带过投研 App 或配置产品。
- **没有做过客户资产配置 / 投顾组合 / FOF。** 股票池和赛道轮动只能当「研究侧的配置参考」，不能说成资产配置产品。
- 真实使用者主要是看盘同事和自己，不是大规模专业客户。
- 个人账户收益不能说成产品或基金业绩。
- 没有社交媒体分享产品构建的公开记录，加分项 2 不要硬凑。
- 雇主未知，面试前不要装了解「你们最近发的 X」。
