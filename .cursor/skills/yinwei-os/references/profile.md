# 殷维剖面（决策用，不是简历）

表层技能会变。下面这些是选 A / 选 B 时真正该看的。

## 1. 表层技能（可学，不拿来定义人）

金融：投研框架、财务选股、尽调报告、因子回测、Wind / Tushare。  
AI 落地：Cursor / Claude / MCP、Coze 工作流、知识库、LangGraph 小流程、研报/扫描自动推送。  
远程已做过：金融专家标注、量化工作室协同。  
表达：冷面段子、分镜、把经历写成故事。

这些说明「能接什么活」，不说明「该过什么样的日子」。

## 2. 底层能力（改不了，决定适配）

| 底层 | 表现 | 市场误读 |
|---|---|---|
| 传递 / 翻译 | 内行 → 人话；把同事带会 | 「不善沟通」 |
| 卸防 | 人来倾诉、觉得宝藏 | 职场不计分，被当软 |
| 异步深度 | 文字、搭建、结构比现场强 | 能力被打成折扣价 |
| 结构化提问 | 能把乱收成问题 | 看起来不像专家 |
| 理念关联 | 段子三层、诊断命名 | 闲散、半瓢水 |
| 过程型做成 | 工作流 1.0、知识库、推送 | 净值组织里不算功劳 |
| 金融母语 | 黑话、流程、尽调都懂 | 被塞进交易员考场 |
| 自我观察 | 参数说得清 | 被说成矫情 |

## 3. 兴趣 / 出口（吸引传感器的已有数据）

做完还想继续的：视频/段子、拆分镜、搭 AI 工作流并被人用、把处境讲清楚、写成故事或哼成歌。  
快乐但不满足：跳舞。维护：健身。  
做了会灰：盯盘、优化策略、办公室表演、被指导人格、2B 复杂流程。

## 4. 已知约束（简历时长已按她更正）

- 人际不安全：约 4 个月。
- 人际尚可但任务错：6–14 个月。
- 「两个都对」还没有完整样本。
- 评价型环境耐受约 2–3 个月后收缩。
- 被指导、被否定：一晚不想做事。跟人说话一整天，只要不评价，还撑得住。
- 太自由躺平；太管逃避。要脚手架：节律 + 边界 + 没人盯。
- 2B 企业内她已判「过于复杂」。2C 或边界清楚的小项目更合适。

## 5. 三层结构（所有选择必须落到一层）

| 层 | 职责 | 形态 |
|---|---|---|
| 底层 | 钱、节律、缓冲 | 短周期岗 / 标注 / 边界清楚的搭建包 |
| 中层 | 认可、作品、疗愈传播 | 2C 文字/视频/故事；像作家投稿 |
| 顶层 | 期权 | 书、系列、以后才谈的产品 |

一层不能要求另一层的功能。底层不负责燃；中层前半年不负责养家。

## 6. 作家路径（执行逻辑）

不是先成为作家再写。是：

1. 每周投出 1 个小作品（视频、短文、故事、一段歌词）。
2. 每来一个活，先过 `decide.py`，再接。
3. 只在「做完还想继续」的事上加深，那就是主线长出来的地方。
4. 12–18 个月看：缓冲、是否有付费小项目、作品是否还在。

## 7. 常见市场选项的预判

| 选项 | 层 | 倾向 |
|---|---|---|
| 当前 AI 投研（搭建工作流/知识库/推送） | 底层 | 条件留：只做过程型搭建，量化结果考核一漂就标红 |
| 金融专家标注 / 远程小单 | 底层 | 可接，干净 |
| 客服机器人训练 | 底层 | 能做、费力、偏 2B；当短项目可以，不当身份 |
| 投研 AI 搭建外包（熟人，有边界） | 底层 | 更匹配「赋能者」 |
| 企业 AI 咨询 / 对公客户 | 错层 | 默认不接 |
| 2C：迷失→自学 AI→一种可能 | 中层 | 主表达。不保证别人就业 |
| 段子 / 写成歌 | 中层出口 | 先发布，不先变现 |
| 奇门咨询、陪伴机器人、一对一疗愈 | 错层 | 否决当主业 |
| 窗口/编制 | 底层备选 | 只看编制+派驻+备考不毁中层 |
